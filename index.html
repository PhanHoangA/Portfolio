Cinema Booking System (C# / ASP.NET Core)

Project Overview

A comprehensive web application designed for multiplex movie theaters to manage film screenings, auditorium configurations, and real-time ticket reservations with seat locking, developed with C# and ASP.NET Core MVC.

Architectural Highlights & Features:
  • ASP.NET Core MVC Architecture: Clean separation of concerns with Controllers, Models, and strongly typed Razor Views.
  • Interactive Seat Matrix: Visual seating grid generated dynamically from auditorium capacities with real-time seat lock verification.
  • Entity Framework Core: Handles data models, migrations, and transactional seat booking to prevent double-booking collisions.
  • Showtime Scheduling & Admin: Role-based access for theater staff to schedule movie screenings, assign halls, and generate booking invoices.
C# ASP.NET Core Entity Framework Core SQL Server MVC Pattern

Restaurant Table Reservation

Project Overview

A modern RESTful backend service built on the Spring ecosystem to streamline table bookings, guest count management, and dining slot availability in real time.

Architectural Highlights & Features:

Student Attendance Management (C# / .NET)

Project Overview

A native Windows desktop application built with C# and .NET (independent of Java) to automate student roll calls, course enrolments, absent quotas, and academic report exports.

Architectural Highlights & Features:
  • Built with C# & .NET 8: Leverages the modern .NET desktop runtime, typed C# records, and LINQ queries.
  • WPF MVVM Architecture: Two-way XAML data binding with INotifyPropertyChanged and RelayCommands for responsive UI.
  • Entity Framework Core: Code-first migration workflow with SQL Server backend and LINQ optimization.
  • Attendance Quota Calculation: Automatically flags students whose absentee rate approaches the 20% course threshold.
  • Data Exporting: Direct export of attendance sheets to formatted Excel spreadsheets for university administration.
C# .NET 8 WPF (XAML) Entity Framework Core SQL Server
